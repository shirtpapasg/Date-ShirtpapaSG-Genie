## Big idea
Electricity can harm: keep wet hands, overloaded sockets, frayed wires and metal objects away from the mains; use electricity wisely (switch off, choose efficient appliances); a circuit toy needs a complete loop and a switch to control it.

## Misconceptions to bust
- "A device that is switched on but not being used takes no electricity." → It still uses electricity; switch it off (lab 6.5 trap "Only a screen that is being watched uses any electricity at all"; content_map Ch 6). **Becomes the `tip` beat.**
- "Removing or switching off one bulb switches everything off." → A switch on one parallel path opens only that path (content_map Ch 6 "removing any bulb switches everything off"). **Wrong quiz option A.**
- "A frayed wire is only unsafe once someone touches the bare metal." → The bare metal is a hazard before anyone touches it (lab 6.5 Part (a) prediction reason).
- "Switching a lamp on and off uses more electricity." → Switching off when not needed uses less electricity over a day (lab 6.5 prediction reason).
- "The parts of a toy do not need to be joined, because they are all inside the toy." → Every part must be joined in one complete loop (lab 6.6 trap).
- "The battery can be switched off, so no switch is needed." → A switch in the loop turns the light on and off without pulling a wire loose (lab 6.6 prediction reason).
- "A plug's case is plastic to make it safe" given as the property. → The property is that plastic is an electrical insulator; safety is the use (Mix-up buster #21). Description only (taught in EP 24).

## Pause and predict
**Q:** A toy has two bulbs, X and Y, on separate parallel paths. A switch sits on bulb X's path only. The switch is opened. What happens?
- A. Both bulbs go out. (misconception: removing or switching off one bulb switches everything off)
- B. X goes out, and Y stays lit.
- C. Both bulbs stay lit.
- D. Y goes out, and X stays lit.

**Answer: B.** Reason: the open switch makes a gap on X's path only; Y has its own closed path, so it stays lit.
Rule check: a new situation (a switch on one parallel path has not been shown in this or the last episode); the stem does not say "own closed path" or "gap"; the `tip` beat before `quiz1` is about a TV left on, not switches on paths.
