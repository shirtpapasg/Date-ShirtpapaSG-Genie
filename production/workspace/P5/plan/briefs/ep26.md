## Big idea
In a parallel circuit each bulb has its own path from the battery; the bulbs stay as bright as one bulb alone, and when one bulb is removed the others stay lit; homes use parallel arrangements so one switched-off lamp does not switch off the rest.

## Misconceptions to bust
- "Parallel bulbs share the brightness, so each gets dimmer as more are added." → Each bulb has its own path and stays as bright as one bulb alone (lab 6.3 trap and prediction reason "The battery must now be shared between more paths"; content_map Ch 6). **Becomes the `tip` beat.**
- "Removing any bulb switches everything off." → In parallel, the other bulbs stay lit (content_map Ch 6; lab 6.4 trap). **Wrong quiz option C.**
- "Each room has its own path, however it is wired." → Only parallel wiring gives each its own path; wired in series, one bulb out switches the other room off (lab 6.4 Part (b) prediction reason).
- "Bulbs are brighter" with no comparison. → Brighter than the same bulbs in series (6.7; `app_p5.md` 6.3 script check).
- "In a mixed circuit, one bulb out means only that bulb goes out." → A bulb sharing a path with it goes out too (quiz option B, 6.8 applied to one path).

## Pause and predict
**Q:** Bulb P sits on its own path. Bulbs Q and R sit one after another on a second path, from the same battery. Bulb Q is taken out. Which bulbs stay lit?
- A. P only.
- B. P and R.
- C. None of them. (misconception: removing any bulb switches everything off)
- D. R only.

**Answer: A.** Reason: Q and R are on one path, so taking Q out opens that path and R goes out too; P has its own closed path, so it stays lit.
