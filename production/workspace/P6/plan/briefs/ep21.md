## Big idea
When the prey population rises, the predator population rises after it; fewer predators means more prey; competition for food, water, space or light makes a population smaller; removing one organism from a food web changes the others.

## Misconceptions to bust
- More predators make the prey extinct → the prey population decreases (lab 4.4 planned mix-up; `definitions_p6.md` 4.18). **Becomes the `tip` beat and quiz option D.**
- Removing one organism changes only the organisms it eats or is eaten by → changes pass along the web, link by link (poster: "Remove one, the others change"). **Becomes quiz option C.**
- Removing a predator makes everything increase → the prey increases, but then the prey's food decreases (quiz answer).
- Predator numbers never change, only prey does → predator population follows the prey (lab 4.4 Part (b) wrong reason).
- Competition only happens between different kinds → seedlings of one kind in one pot compete too.
- Predators only eat old or weak prey, so numbers do not change (lab 4.4 Part (c) wrong reason) → more predators decrease the prey population.

## Exam wording box
1. More prey increases predator population; less prey decreases predator population. (4.18, Recitation Ch 4)
2. More predators decrease prey population; fewer predators increase prey population. (4.18, Recitation Ch 4)
3. Structured answer (cause → process → result): The snakes are removed, so there are fewer predators. Fewer frogs are eaten, and the frog population increases.
