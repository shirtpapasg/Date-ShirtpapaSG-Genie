## Big idea
PSLE-style forces questions: which forces act on a biscuit held by tongs (frictional and gravitational), which forces act on a block sliding then stopped (frictional while moving, gravitational always), why a block slides further on a smoother surface, why an experiment is repeated three times, why a launcher beats a finger (same force every time: a fair test).

## Misconceptions to bust
- "List every force you can think of." → Name only the forces present; extra wrong forces lose marks (content map Ch 3; answer key Set 2 Q41a). **Becomes the `tip` beat.**
- "Repeating the test changes it, so it is less fair." → Repeating makes the results more reliable (row 3.43). **Becomes quiz option B (a wrong option).**
- "A finger push is as good as a launcher." → A finger may push with a different force each time; the launcher gives the same force, so only the surface changes (row 3.43). **The quiz answer C.**
- "A stopped block has frictional force on it because it is on a surface." → Frictional force opposes motion; at B there is no motion to oppose (row 3.41; Q3 answer (2)).
- "A stopped object has no forces at all." → Gravitational force acts on objects all the time (row 3.28).
- "Gaining heat is a force." → A force is a push or a pull (row 3.40).
- "A longer table makes the block go further." → Only a smoother surface (less frictional force) does (Q4 answer (4)).
- "The block on Z stopped because the push ran out." → Frictional force opposed its motion (row 3.14).

## Exam wording box
1. The block moved a greater distance on surface Y than on surface Z.
2. Structured answer (cause → process → result): Surface Z exerted a greater frictional force on the block than surface Y. The frictional force opposed the block's motion, so the block slowed down and stopped in a shorter distance on Z.
3. The launcher pushes the block with the same force every time, so only the surface is changed and the test is fair. (Q6b, shown in `q6ab`: the experiment was repeated three times to make the results more reliable.)
