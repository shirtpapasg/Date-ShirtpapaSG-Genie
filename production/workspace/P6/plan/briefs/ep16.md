## Big idea
Elastic spring force is the push or pull exerted by an object that is stretched or compressed; it makes the object return to its original shape; the more force needed to stretch or compress it, the more elastic spring force it exerts; a spring's length increases as the mass hung on it increases (the book's table); playgrounds use it (trampoline, spring rider).

## Misconceptions to bust
- "Elastic spring force acts only when a spring is stretched." → It is exerted by an object that is stretched OR compressed (p. 65–66). **Becomes the `tip` beat.**
- "Gravitational force pushes you up on a trampoline / pogo stick." → Elastic spring force pushes up; gravitational force pulls down (p. 67; p. 60). **Becomes quiz option B.**
- "One force does everything (the spring pushes up and pulls down)." → Two different forces act. **Quiz option D.**
- "A heavier object makes the spring shorter." → The length of the spring increases as the mass increases (p. 70 table).
- "Describe the relationship" answered with one variable only ("the spring gets longer") → name both: the mass of the object and the length of the spring (PSLE answer frame).
- "The spring expands / contracts." → Springs stretch (extend) or are compressed (app mix-up 28; row 3.36). The narration never says expand or contract.
- "A stronger spring" → a stiffer spring: more force is needed to stretch or compress it (row 3.37; app mix-up 19). The `more` beat says "stiff".
- "Once stretched, a spring stays long." → Elastic spring force makes it return to its original shape when the object is removed (p. 66; Q5 hint p. 70).

## Exam wording box
1. Elastic spring force is the push or pull exerted by an object that is stretched or compressed.
2. As the mass of the object increases, the length of the spring increases.
3. Structured answer (cause → process → result): The object stretched the spring. The stretched spring exerts an elastic spring force, so when the object is removed, the elastic spring force makes the spring return to its original length.
