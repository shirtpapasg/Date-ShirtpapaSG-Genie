## Misconceptions to bust
- For the exam, use the book's reason for the maglev train: the magnets on the train and the track repel one another. (Not a ✗ on "magnets attract it upward": some real maglev trains do float by attraction.)
- "The crane uses a normal magnet." It is an electromagnet, so it can switch off and drop the load.
- "The crane picks up everything metal." Only iron and steel objects.
- "Magnets push away non-magnetic things." A non-magnetic object is simply not attracted (the quiz).
- "A magnet toy works by luck." Choose which poles face on purpose: unlike to pull, like to push.
