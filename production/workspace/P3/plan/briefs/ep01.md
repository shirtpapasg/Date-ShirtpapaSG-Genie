## Big idea
There is a great variety of living and non-living things around us (diversity); we classify them by their similarities and differences, and a classification can be shown as pictures, a table or a graphic organiser.

## Misconceptions to bust (as "Exam tip")
- "It moves, so it is living" (toy car, robot dog, puddle). Moving because something pushes it is not a clue.
- "It is still, so it is non-living" (a seed, a sleeping puppy).
- Judging by looks (fur, eyes, colour). Sort by what a thing can do.
- Do not state whether viruses are living or non-living (the book leaves it open; see Description note).

A sleeping puppy / a robot dog that walks and barks / a seed in a packet. **Answer: B.** The robot dog moves and makes sounds, but it does not grow, need food or reproduce; the puppy is alive even when asleep; the seed can grow.
