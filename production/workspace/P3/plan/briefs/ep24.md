# EP 24 — Was that test fair? Change only one thing

## Big idea
An experiment answers a question or tests a prediction; in a fair test only one variable is changed, the other variables are kept the same, and one thing is measured; repeating the test makes the results reliable.

## Misconceptions to bust
- "Changing several things at once is fine." Only one variable changes.
- "Testing once is enough." Repeat for reliable results.
- "A kept-the-same variable can be vague." It must be exact (same type of nail, same number of turns).
- "Only the thing you change is a variable." The things kept the same are variables too (7.9).
- Let's Apply Q1: the magnets must be held at the same distance above identical trays; Q2(b): the number of turns must be the same.

## Exam wording box
1. To conduct a fair test, scientists need to ensure that only one thing (called a variable) is changed. The other variables are kept the same.
2. If the experiment is not fair, we will not be sure which variable can explain the results.
3. It is also important to repeat the experiment a few times to ensure that the results are reliable.
