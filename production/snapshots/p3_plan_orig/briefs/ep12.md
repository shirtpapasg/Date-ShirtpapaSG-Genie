# EP 12 — Why isn't a trolley made of glass? Choosing materials

## Big idea
The physical properties of a material allow it to be used in certain ways: an object can be made from different materials, and one object can use many materials, each chosen for its part's job.

## Misconceptions to bust
- "Fabric for a raincoat because it is soft." Choose for the job: the raincoat must keep water out.
- "A material has only one useful property." The fish tank needs transparent AND waterproof (app M-34).
- "Any material works if it looks nice." The property must suit the intended use.
- Answer pattern: property, then the link to the job.

## Exam wording box
1. Every material has physical properties. The physical properties of a material allow it to be used in certain ways.
2. An object can be made from different materials. The choice of materials depends on the use of the object.
3. The materials are selected for the different functions of the parts based on their physical properties.
4. "Why is X made of Y?" = name the property, then link it to the object's job (e.g. glass is transparent, so light passes through and the user can see clearly).
