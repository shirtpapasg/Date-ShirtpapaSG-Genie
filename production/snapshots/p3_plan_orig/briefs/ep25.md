## Misconceptions to bust
- "The maglev train floats because magnets attract it upward." It floats because like poles repel.
- "The crane uses a normal magnet." It is an electromagnet, so it can switch off and drop the load.
- "The crane picks up everything metal." Only iron and steel objects.
- "A magnet toy works by luck." Choose which poles face on purpose: unlike to pull, like to push.
