# EP 11 — See-through, blurry or blocked? Light and materials

## Big idea
Transparency is how much light can pass through a material: transparent materials let most light through, translucent materials only some, opaque materials none.

## Definitions to use word for word
- 3.19 "The transparency of a material refers to how much light can pass through it."
- 3.20 "Some materials allow most light to pass through them. These materials are transparent." ("Glass and some plastics are transparent." / "You can clearly see objects placed behind transparent materials.")
- 3.21 "Some materials allow only some light to pass through them. These materials are translucent." ("Frosted glass and some plastics are translucent.")
- 3.22 "Some materials do not allow any light to pass through them. These materials are opaque." ("Rubber, wood and metal are opaque materials.")
- Note: the app's syllabus file lists the three terms as not required at P3, but the book teaches them; teach "most / some / no light" first, then the terms (teacher's rule: every named term is a key word).

## Misconceptions to bust
- "Translucent means a little bit transparent." It means only some light passes, so objects behind are not seen clearly.
- "All plastic is transparent." Some plastics are transparent, some translucent.
- "Opaque means dark-coloured." It means no light passes (a white wooden door is opaque).

## Exam wording box
1. The transparency of a material refers to how much light can pass through it.
2. Transparent: most light passes through; you can clearly see objects behind (glass, some plastics).
3. Translucent: only some light passes through; you cannot clearly see objects behind (frosted glass, some plastics).
4. Opaque: no light passes through; you cannot see objects behind (rubber, wood, metal).
