# EP 22 — Turn a nail into a magnet (the stroke method)

## Big idea
A magnetic object (iron or steel) can be magnetised by the stroke method: stroke it with one pole of a strong magnet, in the same direction, with the same pole each time; more strokes make a stronger magnet.

## Misconceptions to bust
- "Copper or wood can be stroked into a magnet." Only magnetic materials (iron, steel).
- "Rub back and forth." One direction, one pole, lifting away between strokes.
- "Switching poles halfway is fine." Same pole every stroke.
- "One or two strokes is enough." More strokes make a stronger magnet.

## Exam wording box
1. A magnetic object can be made into a magnet using the stroke method or the electrical method. When a magnetic object becomes a magnet, we say that it has been magnetised.
2. Stroke the iron nail with one pole of a bar magnet. Repeat the strokes in the same direction each time. Make sure to stroke the iron nail with the same pole.
3. Test the magnetised iron nail by placing it near some steel clips.
4. The iron nail will become a stronger magnet when it is stroked more times with the magnet.

## Realism notes
- The stroking pole (say N, red) touches the nail and moves along it in ONE direction (head to tip), then lifts away in an arc and returns to the start; never slides back along the nail.
- The nail is grey iron with a flat head and a point; steel clips hang from the nail's ends (poles), especially the tip.
- Stroke counter and clip chart use spoken numbers ("ten", "thirty") for cues.
