TheOneApp Publisher

Evidence for the YouTube API Services compliance audit · Google Cloud project 780560926873 · 12 October 2026

What the API client is. TheOneApp Publisher is a private command-line tool used by one person, the teacher who runs TheOneApp (theoneapp-sg.vercel.app), to publish the teacher's own educational science videos to the teacher's own YouTube channel, TheOneApp. It has no other users and no user accounts.

Endpoints used

EndpointWhy
channels.list (mine=true)Find the signed-in owner's channel and its uploads playlist
playlistItems.listFind each uploaded episode on the owner's channel
videos.insertUpload a finished episode (once the project is audited)
videos.list, videos.updateSet title, description, tags, category, language, made-for-kids, visibility
thumbnails.setUpload the episode's custom thumbnail
playlists.list, playlists.insert, playlistItems.insertKeep every episode in the series playlist "TheOneApp, Explained"

1. OAuth flow

The tool uses Google's OAuth 2.0 device-code flow (OAuth client type "TVs and Limited Input devices"). It requests one scope, https://www.googleapis.com/auth/youtube, which is needed to upload and edit the owner's own videos and playlists. Nothing is read from any other account.

Step 1 · the tool asks for sign-in

$ python3 production/youtube/yt_device_login.py start
Open this link in your browser:  https://www.google.com/device
Enter this code:                 SYL-HFH-VTNT
The code is valid for 30 minutes. Then run:  python3 yt_device_login.py wait

Step 2 · Google's consent screen

The owner opens google.com/device, enters the code, chooses the channel's Google account, and sees the standard Google consent screen for "TheOneApp Publisher" listing the YouTube permission. After approval Google shows "Success! Device connected". The screens below are the ones the channel owner saw on 11 October 2026.

ScreenWhat it showed
Sign in with Google · TheOneApp PublisherConsent request for the YouTube scope, approved by the channel owner
Success! Device connected · TheOneAppConfirmation after approval

Step 3 · the tool receives the token

$ python3 production/youtube/yt_device_login.py wait
Waiting for your approval in the browser…
Tokens stored in production/youtube/.yt_token.json (refresh token: yes)

The token file is readable by the owner only (mode 600), is excluded from version control, and lives only in the owner's private workspace. The tool never prints a token.

Revocation

The owner revokes the tool's access at any time at security.google.com/settings/security/permissions ("Third-party apps with account access" → TheOneApp Publisher → Remove access). The stored token then stops working. The privacy policy and terms both state this.

3. Player / embed

The published videos appear on the Videos page of TheOneApp, played through YouTube's privacy-enhanced embedded player (youtube-nocookie.com, with the standard YouTube controls and branding). The page states that the lessons play from the YouTube channel and links the channel, the privacy policy and the terms. Episodes 1 to 5 are "Now showing"; the rest are "Coming soon" until published.
