TheOneApp Publisher · user flows

Flow A: the channel owner publishes an episode · Flow B: a pupil watches it in TheOneApp

Flow A · publishing (channel owner only)

1Sign in onceRun yt_device_login.py start. The tool shows a code and google.com/device.Google device-code flow, scope youtube
2Approve on GoogleOwner enters the code, picks the channel account, sees the consent screen naming the YouTube permission, clicks Allow.Revocable later at Google security settings
3Dry runRun publish_p4.py --dry-run. The tool lists each episode it found and what it would change. Nothing is written.channels.list, playlistItems.list
4PublishRun publish_p4.py --privacy public: upload (videos.insert), set title, description, tags, category, language, made-for-kids (videos.update), thumbnail (thumbnails.set), playlist.Report written with each video link

Flow B · watching (pupils)

1Open TheOneApptheoneapp-sg.vercel.app · Videos. No sign-in. The page says lessons play from the YouTube channel and links the privacy policy and terms.
2Choose an episodePick a “Now showing” episode on the Primary 4 shelf.
3Watch on YouTube's playerThe video plays in YouTube's privacy-enhanced embedded player with standard YouTube controls. “Watch it on YouTube” opens the video on youtube.com.
4Test yourselfAfter the video, the app offers a quiz on the same topic. The app makes no YouTube API calls.
