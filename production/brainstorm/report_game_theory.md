# Lens 1 (game theory): "Lock It In! (Beat Bolt)" — summary of the Fable agent's report (19 Nov 2026)
- Every episode is a 5-point match: viewer vs Bolt, an over-confident robot who answers with "common sense" (real misconceptions), right ~1 round in 3. Answer hand (fingers) + score hand (one finger per point; perfect game = open hand = high five). No lock-in = "you ride with Bolt" (default option is a poor one).
- Skeleton (6:00): silent cold open → mission + rules (15 s) → Round Zero: Bolt's revenge question from last episode (streak, spaced retrieval) → Round 1 easy (set-up 15 s, lock clock 8 s, Bolt's guess AFTER the lock, race 15 s, verdict + keyword 20 s) → Round 2 → FOUL! (Bolt runs an unfair test; cross arms on spotting it) → Round 3 BOLD (Safe = 1, Bold = right 2 / wrong -1; hand on head) → Fix Bolt (Heart starts exam sentences, child finishes the keyword aloud) → show score hand, titles for every score, collector card + code word, next revenge question.
- Classroom: eyes shut while voting (stops herding), class vs Bolt (cooperative), pair talk + re-vote when split, teams decide Bold/Safe, corner pause icon at 3 points.
- Evaporation "Dry by 7 a.m.": Tampines HDB, Ming's PE shirt; Round 1 pail vs pole (surface area), Round 2 fan vs still air (Bolt: cool air = slow), Foul: sun+spread vs shade+crumpled → re-run with wet footprints sun vs shelter (temperature), Bold round humidity (dry Monday vs after-rain Tuesday, Bolt bets tie and loses), Fix Bolt fills "larger exposed surface area / more wind / higher temperature / lower humidity". Code word POLE.
- Mechanics with game-theory reasons: default option (riding with Bolt), simultaneous move (Bolt speaks after the lock), no dominant shortcut (Bolt right 1 in 3), cheap commitment (fingers), self-scoring with no payoff for cheating, face-saving rival, risk/reward betting trains calibration, standing Foul rule rewards attention to test set-up, anti-herding, cooperative play vs common opponent, streaks.
- Pause: never ask for pause, never dead air; 8 s clock with music; tiny task; funny consequence of doing nothing; reveal speaks to the gesture. Honest expectation: in class nearly all; alone at home a third to a half, rising as Bolt becomes familiar.
- App: tap-to-lock, confidence chips, tracked streaks, card album via code word, class code with live vote split on the teacher's screen, "Train Bolt" (build the open-ended answer from keyword tiles).
- Measure: matched classes, quiz now and a week later; hands up per lock in class; YouTube retention at lock beats; code-word entries per view; app lock-in rate and Bold accuracy.
