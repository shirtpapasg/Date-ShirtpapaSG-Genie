# Lens 3 (kids' media): "Beat the Mynah" — summary of the Fable agent's report (19 Nov 2026)
- Three-round prediction game in one real Singapore problem with a deadline; the viewer is the contestant; rival Chop, a cheeky mynah (simple SVG: black oval, yellow beak and eye patch; poses smug/shocked/soaked/sulking/clapping; a good sport). Heart = fair, warm host who never says a wrong thing. A hidden cicak (house gecko) each episode for a "did you spot it" hook. Season score You vs Chop.
- Title pattern: dare first, topic last ("Can You Dry a PE Shirt by 7.30 am? Beat the Mynah | P5 Evaporation"). Thumbnail: problem object + Chop's face + 3-word dare, same layout every time.
- Skeleton (~6 min): cold open with deadline (0:00) → the dare + rules + season score + cicak (0:12) → the one idea as a short first-person close-up (0:30) → Round 1 winnable before 1:00 → Round 2 big physical fail at the ~30% retention dip → Round 3 twist: Chop right for the wrong reason, no point (stops "pick opposite of Chop") → Showdown double points + spot the mistake in Chop's written exam answer → payoff: problem solved, Mark Sentences replay as a "win strip" → hooks out (cicak, "Chop's Revenge" next dare), hard cut. Running gag/fair-test rule of three: "Change one thing. Keep the rest the same. Measure."
- Pause: replace "pause" with a lock-in: Chop commits first (someone to disagree with), answer is a movement (point left/right), 5-6 s max, screen never still, music drops to an accelerating woodblock, bell, "Locked in!"; shout gaps (~2 s) for keywords; skippers lose nothing; class bell icon = teacher pause point; checked answers in TheOneApp where the video waits.
- Shorts: one round alone ending on the next question; "Spot Chop's mistake"; a misconception buster. Every Short ends on a correct statement.
- App: real lock-in with the video waiting; cicak location → a "chop" stamp in a chop book; build Mark Sentences from keywords; 4-slider evaporation lab with a class tally; start by reusing "moments".
- Risks: Chop's wrong ideas never in Heart's voice and crossed out within seconds; "Confirm plus chop" is Singlish (teacher's call; fallback "Lock it in!"); real test data; Mark Sentence wording to be checked against the textbook; cap 4 Mark Sentences.
- Measure: retention at 0:30, average % viewed vs the current Explained episode on the same topic, graph shape at each lock-in, bumps (rewatches), returning viewers, Shorts→long conversion; app code entries and Mark-Sentence quiz scores.
